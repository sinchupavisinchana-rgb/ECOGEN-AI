# 🌍 ECOGEN AI
### Intelligence for a Greener Tomorrow

**ECOGEN AI** is an AI-powered Environmental Intelligence Platform designed to monitor environmental conditions, analyze ecological data, and support sustainable decision-making through intelligent technologies.

The platform brings environmental insights into a unified dashboard with a focus on air quality, forest coverage, climate intelligence, environmental risk analysis, and AI-assisted environmental awareness.

---

## 🚀 Project Overview

Environmental challenges such as air pollution, deforestation, climate change, and increasing carbon emissions require intelligent monitoring and analysis.

ECOGEN AI aims to transform environmental information into meaningful insights using Artificial Intelligence, Machine Learning, data analytics, and interactive visualizations.

## ✨ Key Features

- **Environmental Dashboard** – Centralized environmental monitoring interface.
- **Air Quality Intelligence** – Air Quality Index monitoring and analysis.
- **Global Environmental Map** – Planned geographical environmental visualization.
- **Deforestation Monitoring** – Environmental forest coverage insights.
- **Climate Intelligence** – Climate-related analysis and future prediction capabilities.
- **Environmental Risk Engine** – Environmental risk scoring and assessment.
- **AI Eco Assistant** – Planned AI-powered environmental assistance.
- **Reports & Analytics** – Environmental insights and reporting.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/sinchupavisinchana-rgb/ECOGEN-AI.git
```

### 2. Navigate to the Project

```bash
cd ECOGEN-AI
```

### 3. Setup Frontend

```bash
cd frontend
npm install
npm install lucide-react axios recharts react-leaflet leaflet
npm run dev
```

Frontend URL:

```text
http://localhost:5173
```

Use the actual port displayed by Vite if it selects another port.

### 4. Setup Backend

Open another terminal:

```bash
cd backend
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install fastapi uvicorn pandas numpy scikit-learn joblib python-multipart
```

Start FastAPI:

```bash
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Backend URL:

```text
http://127.0.0.1:8000
```

API documentation:

```text
http://127.0.0.1:8000/docs
```
